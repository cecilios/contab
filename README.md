# contab

Aplicación web local de uso personal para la gestión básica de inmuebles alquilados, facturación, control de ingresos y gastos y, especialmente, automatización asistida de la conciliación de movimientos bancarios.

La descripción funcional, objetivos y alcance del proyecto se encuentran en [PROJECT.md](docs/PROJECT.md).

La arquitectura, herramientas, convenciones y estado del desarrollo se documentan en [DEVELOPMENT.md](docs/DEVELOPMENT.md).
